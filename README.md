The project starts with a Splash Screen that introduces the Tasteory application. Initially, I planned to use an external image as the background, but due to asset loading issues, I replaced it with a soft brown gradient background that better matched the overall design

<img width="608" alt="first (2)" src="https://github.com/user-attachments/assets/7e33e0d7-ab24-4885-b26e-c89b4106c356" />

After the Splash Screen, the user enters the main categories page, where different meal categories are displayed. The user can select a category to explore the available meals.

<img width="300" alt="second (2)" src="https://github.com/user-attachments/assets/2c4ad864-ced5-482a-8d43-90d1d29351cb" />
<img width="300" alt="third (2)" src="https://github.com/user-attachments/assets/f5b95952-e13b-4243-b1d0-217afa716410" />

After selecting the Pasta category, the user can browse a variety of pasta meals displayed in an organized layout. Each meal card allows the user to select a specific dish and view more details.

<img width="300" alt="fourth (2)" src="https://github.com/user-attachments/assets/de5b69a7-5bcd-4031-a61c-859633e8de74" />
<img width="300" alt="fourth (3)" src="https://github.com/user-attachments/assets/721dfcf1-fafa-4084-87f9-577267496f7c" />

Finally, when the user selects a specific meal, they are taken to the meal details page. This page displays detailed information about the selected dish, including its image, preparation time, difficulty level, number of servings, and a brief description.
